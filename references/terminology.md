# 术语一致性规则

翻文档翻车，八成死在术语上。这份规则是硬约束，不是建议。

## 一、候选术语怎么抽

从 `map.json` 里按顺序扫，收这几类：

1. **重复出现的名词**（出现 ≥ 2 次）：`清洁验证`、`残留限度`
2. **型号与料号**：`TX-201`、`630 不锈钢`
3. **缩写与首字母词**：`MDR`、`UDI`、`IFU`、`SOP`
4. **法规与标准编号**：`MDR (EU) 2017/745`、`ISO 13485:2016`、`GB/T 16886.1`
5. **量与单位**：`μg/cm²`、`EU/mL`、`°C`
6. **人名、机构名、产品名**：保持原文或按用户给定译法

## 二、状态标记（三态，不允许第四态）

| 状态 | 含义 | 谁定的 |
|---|---|---|
| `用户指定` | 用户给了术语表 / 明确说过译法 | 用户 |
| `已确认` | 我列出来，用户点了头 | 用户 |
| `待确认` | 我抽出来了，用户还没表态 | 系统 |

**待确认的术语在译文里必须带 `[TC]` 标记**（terminology check），并在交付摘要里单列。不允许悄悄按我的理解翻完。

## 三、绝对不动的

- 法规编号整体：`MDR (EU) 2017/745` 不拆、不译成「欧盟医疗器械条例 2017/745 号」
- 标准号：`ISO 13485:2016` 保留年份冒号格式
- 数字与单位：`10 μg/cm²` 不换算、不改精度、不把 μg 写成 ug
- 型号、料号、批次号、证书号：原样
- 已注册商标符号：`®`、`™` 原样

## 四、目标语种的格式差异（易漏）

| 项 | 中文原文 | 英文译文 | 德语译文 |
|---|---|---|---|
| 小数点 | `0.5` | `0.5` | `0,5` |
| 千分位 | `1,000` | `1,000` | `1.000` |
| 引号 | `“…”` | `"…"` | `„…“` |
| 范围号 | `10–20` | `10–20`（en dash） | `10–20` |
| 序号 | `1.` `2.1` | `1.` `2.1` | 同英文 |

## 五、一致性自查（交付前必跑）

1. 同一源术语在全文**只有一个译法**（大小写变体不算差异，词形变化算）
2. 表格里的术语与正文一致
3. 缩写首次出现时给全称，后续用缩写
4. 标题里的术语与正文一致（最容易漏的地方）
5. 目录/编号在译后仍指向正确位置

## 六、常见雷区

- **一词多义硬统一**：`验证` 在器械语境里常是 validation（工艺）与 verification（检验）两个词，别统一成一个
- **中文四字词直译**：`工艺有效` → `process is effective` 而非 `process effectiveness`（名词化会让英文读起来像 AI 写的）
- **量词消失**：中文「一份文件」的「份」在英文里不需要译，别硬加 `a copy of`
